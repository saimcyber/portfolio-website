The portfolio currently lists three projects but provides no public repository links, so publish evidence before pitching those projects.

Outreach draft, to personalize for a real workshop editor:

> Hi [name], I’ve published the setup guide and sample configuration from [workshop]. It includes [specific useful detail] so attendees can repeat the exercise. If you’re updating the event recap, would this be a useful resource to include? [resource URL]. My author page is https://saimzaib.tech/. Thanks, Saim.

Contact only people whose work or event is relevant. Send one follow-up after a week if appropriate, then stop. Let the editor choose the wording and whether to link. Do not buy ranking links, automate submissions, or arrange bulk link exchanges; Google identifies those practices as link spam. [Google spam policies](https://developers.google.com/search/docs/essentials/spam-policies#link-spam).

Record each prospect, why your resource helps their readers, contact date, reply, published URL, and referral traffic in a simple tracker. Review Search Console's Links and Performance reports monthly. Look for branded impressions for “Saim Zaib,” clicks, and relevant visits. Third-party editors decide whether to publish links; rankings and backlinks are not guaranteed.
